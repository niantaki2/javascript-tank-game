
# JavaScript Tank Game

A simple browser tank game built with vanilla JavaScript, HTML and CSS.

## Features

- WASD tank movement
- Shooting with Space
- Enemy tank AI
- Collision detection
- Health system
- Obstacles
- Win counter

## Play

Live demo:
https://simpletankgame.netlify.app/ 

## Controls

W A S D - Move
Space - Shoot

## Built With

- JavaScript
- HTML5 Canvas
- CSS
